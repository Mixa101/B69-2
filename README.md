# Контрольная работа №2: Доска объявлений

## Задача

Реализовать на Django небольшую доску объявлений: пользователи публикуют объявления о продаже вещей, остальные их просматривают, ищут и фильтруют.

Можно использовать FBV или CBV, как удобнее.

## Модели

**Category** — категория объявления:
- `name` — название

**Ad** — объявление:
- `title` — заголовок
- `description` — описание
- `price` — цена (целое или десятичное число)
- `category` — категория (связь с `Category`)
- `author` — автор (связь с пользователем Django)
- `created_at` — дата создания (заполняется автоматически)

Категории можно создавать через админку: зарегистрируйте модели в `admin.py`.

## Требования к функционалу

1. **Список объявлений** (главная страница)
   - Сначала новые.
   - Для каждого объявления видны заголовок, цена и категория.
   - Пагинация по **5** объявлений на страницу.

2. **Поиск и фильтр**
   - Поиск по заголовку и описанию.
   - Фильтр по категории (выпадающий список).
   - Поиск и фильтр работают вместе; при переходе на следующую страницу параметры не сбрасываются.

3. **Детальная страница объявления**
   - Заголовок, описание, цена, категория, автор, дата создания.

4. **Создание объявления**
   - Форма (желательно `ModelForm`) с полями: заголовок, описание, цена, категория.
   - Доступно только авторизованным пользователям.
   - Автор проставляется автоматически, пользователь его не выбирает.

5. **Редактирование и удаление**
   - Редактировать и удалять объявление может **только его автор**
   - Кнопки «Редактировать» и «Удалить» видит только автор.
   - Удаление выполняется POST-запросом (форма с подтверждением), а не простой ссылкой.

6. **«Мои объявления»**
   - Отдельная страница, где пользователь видит только свои объявления.
   - Доступна только авторизованным.

7. **Вход и выход**
   - Работающий вход и выход (можно подключить `django.contrib.auth.urls`).

## Бонус (+ баллы, но не больше 60 в сумме)

- Регистрация нового пользователя (+2)
- Общий `base.html` с навигацией: Главная / Мои объявления / Создать / Войти–Выйти (+1)

**Важно:**
- Каждая страница должна открываться без ошибок. Перед сдачей пройдитесь по всем страницам руками.
- Миграции должны лежать в репозитории.
- Внешний вид на ваше усмотрение, но страницы не должны выглядеть совсем сырыми.
- В репозиторий не нужно класть `venv`, `__pycache__` и `db.sqlite3`: добавьте их в `.gitignore`.
