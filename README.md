# Контрольная работа: ToDo App

## Задача

Реализовать приложение для управления задачами (ToDo List) на Django.

## Требования к функционалу

Приложение должно предоставлять пользователю возможность:

1. **Просмотреть список задач** — все задачи должны отображаться на одной странице, отсортированные по дате создания (сначала новые). Для каждой задачи должно быть видно: название и статус выполнения.

2. **Посмотреть детали конкретной задачи** — отдельная страница с полной информацией по одной задаче (название, описание, статус, дата создания).

3. **Создать новую задачу** — должна быть форма для добавления задачи с указанием названия и (опционально) описания. После создания пользователь должен видеть задачу в общем списке.

4. **Отметить задачу как выполненную** — должна быть возможность изменить статус задачи с "не выполнено" на "выполнено" (и обратно, по желанию).


## Критерии оценки

- Все 5 операций реализованы и работают корректно
- Данные о задачах сохраняются в базе данных
- Код структурирован и читаем
- Внешний вид — на усмотрение студента, главное чтобы страницы были рабочими и не выглядели полностью сырыми
